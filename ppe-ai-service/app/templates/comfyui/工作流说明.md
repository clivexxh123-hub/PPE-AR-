# ComfyUI 工作流说明

`text_to_image_workflow.json` 是给后端调用的 ComfyUI API 工作流模板，不是普通界面工作流文件。

当前项目已经完成 ComfyUI 调用适配，并已用 Stable Diffusion 1.5 跑通真实出图链路。

本地运行前需要确认两样东西：

1. ComfyUI 里有可用模型文件。
2. `text_to_image_workflow.json` 中的模型名称能在 ComfyUI 中被识别。

当前测试模型：

```text
v1-5-pruned-emaonly.safetensors
```

推荐流程：

1. 启动 ComfyUI。
2. 确认 `CheckpointLoaderSimple` 能看到模型。
3. 启动 PPE AI Service。
4. 调用 `/ai/generate`。
5. 查看返回的 `result_url`。

如果后续更换模型或 workflow，可以重新从 ComfyUI 导出 API Format workflow JSON，并替换本目录下的 `text_to_image_workflow.json`。
